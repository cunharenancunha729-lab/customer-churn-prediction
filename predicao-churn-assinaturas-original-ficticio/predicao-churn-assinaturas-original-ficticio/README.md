# 🤖 Sistema Inteligente de Predição de Cancelamento de Assinaturas

Projeto de **Ciência de Dados e Machine Learning** desenvolvido para analisar o comportamento de clientes e prever cancelamento de assinaturas (*churn*).

## 🎯 Objetivo

Desenvolver e comparar modelos de classificação capazes de identificar clientes com maior probabilidade de cancelamento, utilizando análise exploratória, tratamento de dados, pré-processamento e Machine Learning.

## 🔎 Etapas

- Análise exploratória
- Verificação de valores ausentes e duplicidades
- Tratamento e preparação dos dados
- Seleção de variáveis
- Codificação de variáveis categóricas
- Separação entre treino e teste
- Regressão Logística
- Árvore de Decisão
- Avaliação e comparação dos modelos

## 📈 Resultados do trabalho original

Na execução original do notebook, a **Regressão Logística apresentou 94,44% de acurácia**, enquanto a **Árvore de Decisão apresentou 88,89%**.
